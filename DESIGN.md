# scutilabs — дизайн-ключ

Документ для агента, который приводит проект портфолио к стилю официального сайта scutilabs. ASCII-графика героя сюда не входит. Здесь цвета, шрифты, формы, компоненты и правила.

Источник значений: `src/app/globals.css` и компоненты сайта. Если пункт помечен **[адаптация]**, это правило для интерфейса приложения (CRM, ERP, дашборд), выведенное из стиля сайта. На самом сайте такого элемента нет.

---

## 1. Характер

- **Светлый, бумажный, спокойный.** Холодно-серый фон «бумаги», на нём белые панели с крупным скруглением. Тени почти не используются: глубину дают контраст бумаги и белого и тонкие линии.
- **Монохром плюс один акцент.** Чёрный и серые оттенки делают основную работу. Красный UY Scuti (`#c2371d`) встречается редко: точка, маркер, одна линия графика. Это не цвет кнопок.
- **Космос — в деталях, не в фоне.** Тёмное «небо» используют точечно (превью, блок с результатом). Спектральное свечение (голубой → белый → оранжевый → красный, как классы звёзд O→M) бывает только под главной кнопкой и под тёмными карточками.
- **Типографика крупная и плотная.** Заголовки набраны Google Sans 500 с отрицательным трекингом, текст — Onest.

## 2. Цвета

### Токены

| Токен | HEX | Где используется |
|---|---|---|
| `paper` | `#e6e7ea` | Фон страницы или приложения |
| `panel` | `#f6f6f7` | Вторичная поверхность внутри белого: чипы, ховер пунктов меню, плитки |
| `white` | `#ffffff` | Основные панели, карточки, поля ввода |
| `ink` | `#000000` | Основной текст, заголовки, главная кнопка, фокус-рамка, выделение |
| `ink-2` | `#55565e` | Вторичный текст: лиды, описания, подписи |
| `ink-3` | `#66676e` | Самый мелкий читаемый текст, плейсхолдеры, разделители «/». Проходит AA на белом и на `paper` |
| `ink-4` | `#8a8b93` | **Только декор**: пунктирные обводки, засечки. Не для текста |
| `line` | `#d3d4d9` | Обводки полей, ghost-кнопок, бейджей, строки таблиц |
| `line-2` | `#e7e8eb` | Слабые разделители внутри белых панелей, сетка графиков |
| `scuti` | `#c2371d` | Фирменный акцент: маркер, точка, «как сейчас» на графиках, хвост спектра |
| `demo` | `#2b59c3` | Статус «демо», вторая серия на графиках |
| `dev` | `#a8641c` | Статус «в разработке» |
| `live` | `#17834a` | Статус «работает / в продакшене» |
| `ink-hover` | `#26272c` | Ховер главной (чёрной) кнопки |

### Тёмная поверхность «небо» (sky)

| Слой | Значение |
|---|---|
| Основа | `radial-gradient(130% 120% at 30% 10%, #1e2232 0%, #12141c 50%, #0b0c11 100%)` |
| Туманность, левый верх | `radial-gradient(55% 70% at 0% 0%, rgb(143 168 255 / .20), transparent 70%)` |
| Туманность, правый низ | `radial-gradient(50% 65% at 100% 100%, rgb(255 122 69 / .16), transparent 70%)` |
| Кромка | `inset 0 0 0 1px rgb(255 255 255 / .08), inset 0 1px 0 rgb(255 255 255 / .14)` |
| Тень | `0 22px 50px -26px rgb(16 18 32 / .55)` |
| Текст на небе | `#fff`, вторичный `rgb(255 255 255 / .72)`, мелкий `/.55`, разделители `/.15` |

Подвал сайта — сплошной `ink` (`#000`) со скруглением `1.75rem` и тем же белым текстом с прозрачностью.

### Спектр (фирменный градиент)

```
#8fa8ff → #cfdaff 22% → #fff3e3 44% → #ffc47e 64% → #ff7a45 82% → #c2371d
```

Применяется только как размытое свечение (`filter: blur(9–28px)`, opacity 0.3–0.9) под главной кнопкой или под тёмной карточкой. Не заливайте им фоны, текст или кнопки.

### Правила цвета

1. Главная кнопка — чёрная. Красный никогда не используется для кнопок и ссылок.
2. Текст всегда в оттенках `ink` и никогда в цвете серии или статуса. Цвет несёт точка или линия рядом.
3. Статус = цветная точка 8 px + текстовая подпись. Только цветом статус не передаётся.
4. На графиках: две серии — `scuti` и `demo`. Линии 2 px, сетка `line-2`, подписи осей `ink-3`. У одной серии нет легенды, у двух и больше легенда есть.
5. Фиолетовые градиенты, неон, стекло (glassmorphism) и цветные тени не используются. Единственное исключение — спектральное свечение.

## 3. Шрифты

| Роль | Шрифт | Насыщенность | Подключение |
|---|---|---|---|
| Заголовки (display) | **Google Sans** | 500 | Google Fonts, наборы `latin`, `latin-ext`, `cyrillic` |
| Текст и интерфейс | **Onest** | 400 / 500 / 600 | Google Fonts, наборы `latin`, `latin-ext`, `cyrillic` |
| Код и моно-данные | **JetBrains Mono** | 500 | Google Fonts, набор `latin` |

```css
--font-sans:    "Onest", ui-sans-serif, system-ui, sans-serif;
--font-display: "Google Sans", "Onest", ui-sans-serif, system-ui, sans-serif;
--font-mono:    "JetBrains Mono", ui-monospace, "Cascadia Mono", monospace;
```

Next.js: `import { Google_Sans, Onest, JetBrains_Mono } from "next/font/google"`. У Google Sans поставьте `adjustFontFallback: false`, потому что next/font не знает его метрик.

### Базовый текст

- `body`: 17 px (`1.0625rem`), line-height 1.6, `-webkit-font-smoothing: antialiased`.
- Мелкий текст 15 px (`0.9375rem`), подписи 14 px (`0.875rem`).
- Для `h1–h3` задан `text-wrap: balance`, для `p` — `text-wrap: pretty`.
- Ширина абзаца не больше 56–60 символов (`max-width: 56ch`).

### Заголовки (класс `.display` плюс размер)

```css
.display  { font-family: var(--font-display); font-weight: 500; letter-spacing: -0.03em; line-height: 1.02; }
.h-hero   { font-size: clamp(2.75rem, 6.4vw, 6.25rem); letter-spacing: -0.045em; line-height: .98; }
.h-page   { font-size: clamp(2.5rem, 5.4vw, 4.75rem);  letter-spacing: -0.04em; }
.h-section{ font-size: clamp(2.1rem, 3.8vw, 3.4rem); }
.h-block  { font-size: clamp(1.6rem, 2.2vw, 2.1rem);   letter-spacing: -0.025em; line-height: 1.08; }
.lead     { font-size: clamp(1.125rem, 1.4vw, 1.3rem); line-height: 1.5; color: var(--ink-2); }
```

**[адаптация] Шкала для приложений:** заголовок экрана — display 500, 2rem / −0.03em. Заголовок блока или карточки — display 500, 1.375rem / −0.02em. Подписи полей и колонок — Onest 500, 0.875rem. Данные в таблицах — Onest 400, 0.9375rem, `font-variant-numeric: tabular-nums`. Жирный 700 не используйте: максимум 600, и только для акцентов в тексте.

### Идентификаторы (ID) [адаптация]

- Во всех местах интерфейса ID набираются основным шрифтом интерфейса **Onest** (`font-sans`) и наследуют размер и насыщенность окружающего текста. В таблицах применяется общая типографика ячеек.
- Видимый ID состоит ровно из шести цифр от 0 до 9, без букв, дефисов, пробелов и других разделителей. Примеры: `001001`, `001002`. Начальные нули сохраняются.

## 4. Форма: скругления, линии, тени

| Элемент | Скругление |
|---|---|
| Панель страницы или экрана, подвал, мобильное меню | `1.75rem` (28 px) |
| Карточка, выпадающее меню, форма | `1.5rem` (24 px) |
| Тёмное «небо», вложенная карточка | `1.25rem` (20 px) |
| Плитка внутри карточки, пункт меню | `1rem` (16 px) |
| Поле ввода, select | `0.875rem` (14 px) |
| Тултип, мелкий блок, skip-link | `0.75rem` (12 px) |
| Кнопки, бейджи, чипы, аватары, иконки в кружке | `999px` (pill / круг) |

- Обводка всегда 1 px: `line`, а на ховере `ink-3` или `ink`.
- Таблицы и списки-реестры: верхняя граница группы 1 px `ink` (чёрная), строки разделены 1 px `line`.
- Тени:
  - Карточки без тени: белое на `paper`.
  - Поповер или дропдаун: `0 0 0 1px rgb(0 0 0/.06), 0 24px 60px -20px rgb(0 0 0/.3)`.
  - Тултип: `0 0 0 1px var(--line), 0 12px 28px -12px rgb(0 0 0/.3)`.

## 5. Раскладка

- **Рамка.** Вся страница — набор белых панелей на `paper` с внешним отступом 8 px (≥768 px — 12 px). Шапка фиксированная, с тем же отступом сверху.
- **Контейнер.** `max-width: 82rem`, боковые поля `1.25rem`, с 1024 px — `2.5rem`.
- **Секции.** Вертикальный ритм `5rem`, с 768 px — `7rem`. Панели внутри приложения: padding `1.5rem`, на десктопе `2.5rem`.
- **Сетка.** 12 колонок. Типичное деление текст/визуал — 5/7 или 7/5.
- **Колонные направляющие (опционально, только на маркетинговых страницах).** Вертикальные линии `rgb(0 0 0/.05)` по фону: 4 колонки на мобильном, 6 на десктопе. В плотных интерфейсах приложений их не ставьте.
- Брейкпоинты Tailwind по умолчанию плюс `xs: 30rem`.

## 6. Компоненты

### Кнопки (все — pill)

```css
.btn        { display:inline-flex; align-items:center; justify-content:center; gap:.5rem;
              min-height:3rem; padding:.625rem 1.5rem; border-radius:999px;
              font-size:1rem; font-weight:500; line-height:1.2;
              transition: background-color .2s, color .2s, border-color .2s; }
.btn-primary{ background:#000; color:#fff; }            .btn-primary:hover{ background:#26272c; }
.btn-ghost  { background:transparent; color:#000; border:1px solid var(--line); }
.btn-ghost:hover{ border-color:#000; }
.btn-sm     { min-height:2.5rem; padding:.4rem 1.1rem; font-size:.9375rem; }
```

Главное действие на экране может получить `.btn-glow`: спектральное свечение под кнопкой. На странице такая кнопка одна.

```css
.btn-glow{ position:relative; isolation:isolate; }
.btn-glow::after{ content:""; position:absolute; z-index:-1; left:12%; right:12%; bottom:-.55rem; height:1rem;
  border-radius:999px; filter:blur(9px); opacity:.9;
  background:linear-gradient(90deg,#8fa8ff,#cfdaff 22%,#fff3e3 44%,#ffc47e 64%,#ff7a45 82%,#c2371d); }
```

На тёмном фоне кнопки инвертированы: белая (`bg-white text-ink`) и контурная (`border-white/25`, на ховере `border-white`).

### Поля ввода

```css
.field{ width:100%; border:1px solid var(--line); border-radius:.875rem; background:#fff;
        padding:.75rem .95rem; font-size:1rem; line-height:1.5; color:#000; }
.field::placeholder{ color:var(--ink-3); }
.field:hover{ border-color:var(--ink-3); }
.field:focus-visible{ outline:2px solid #000; outline-offset:1px; border-color:#000; }
```

- Подпись поля стоит над ним: Onest 500 с отступом 0.5rem.
- Чекбоксы, радио и range используют `accent-color: #000`.
- Выбор из вариантов — «чипы»: pill высотой 40 px. Выбранный чип — `bg-ink text-white`. Невыбранный — белый с `ring-1 line`, на ховере `ring ink-3`.

### Ссылки

Подчёркивание 1 px, `text-underline-offset: .22em`, цвет подчёркивания `ink-3`, на ховере `currentColor`. Цвет текста ссылки не меняется.

### Бейдж статуса

Белый pill с обводкой `line`, padding `.25rem .75rem`, 14 px. Внутри точка 8 px нужного статуса (`live`, `demo`, `dev`, `scuti`) и текст `ink`.

### Чип-тег (технология, категория)

`bg-panel`, текст `ink-2`, 14 px, pill, padding `.25rem .75rem`. Без обводки.

### Карточка

Белая, скругление `1.5rem`, внутренний отступ 12 px. Если внутри есть визуал, у него своё скругление `1.25rem`, а текст ниже идёт с отступом `1.5rem 0.75rem 1rem`. Заголовок карточки — `.display .h-block`, описание — `ink-2` с `leading-relaxed`. Вся карточка кликабельна через `::after` ссылки заголовка. На ховере у заголовка появляется подчёркивание, тень не появляется.

### Иконки

[lucide](https://lucide.dev) (`lucide-react`), размер 20 px (`size-5`), цвет `ink` или `ink-2`, толщина линии по умолчанию. Фирменный приём — иконка в кружке 48 px: белый фон, пунктирная обводка 1 px `ink-4`. Эмодзи в интерфейсе не используются.

### Навигация и меню

- Пункт выпадающего меню: `rounded-2xl px-4 py-3`, на ховере `bg-panel`. Заголовок пункта — 500, описание — 14 px `ink-2`.
- Хлебные крошки: 14 px `ink-2`, разделитель «/» в `ink-3`, текущая страница — `ink`.

### Плитки с цифрами (KPI) [адаптация из калькулятора]

Белая плитка `rounded-2xl p-4` на `panel`-подложке. Подпись — 14 px `ink-2`, значение — 1.5rem Onest 500 `tabular-nums` в `ink`. Акцент делается цветной точкой рядом с главным числом, а не цветом самого числа.

### Тёмный блок (результат, превью, пустое состояние, экран входа)

Класс «небо» из раздела 2 со скруглением `1.25–1.5rem`. Опциональный ореол под ним:

```css
.sky{ position:relative; isolation:isolate; border-radius:1.25rem; }
.sky::before{ content:""; position:absolute; z-index:-1; inset:18% 8% -6%; border-radius:2rem;
  background:linear-gradient(90deg,#8fa8ff,#cfdaff 30%,#fff3e3 50%,#ffc47e 70%,#ff7a45);
  filter:blur(28px); opacity:.32; transition:opacity .4s; }
.sky:hover::before{ opacity:.5; }
```

### Мотив полутоновых точек (опционально)

Логотип и «планеты» на сайте нарисованы сферой из точек на квадратной сетке: в центре точки крупнее, к краю мельче, с небольшим смещением к свету. Это допустимый декоративный приём для иллюстраций и пустых состояний, и он не ASCII. Сплошные 3D-иллюстрации и стоковые картинки не используются.

## 7. Движение

- Переходы цвета и обводки — `0.2s`. Свечение и прозрачность — `0.25–0.4s`.
- Появление блоков (`fade-up`): `opacity 0 → 1`, `translateY(6px) → 0`, `0.35s cubic-bezier(.2,.7,.2,1)`.
- Без пружин, параллакса и масштабирования карточек на ховере.
- Обязательно учитывайте `prefers-reduced-motion: reduce`: анимации отключаются, `scroll-behavior: auto`.

---

## 8. Доступность

- Фокус: `outline: 2px solid #000; outline-offset: 3px` на всём интерактивном (`:focus-visible`). На тёмном фоне outline белый.
- Выделение текста: фон `#000`, текст `#fff`.
- Мелкий текст не светлее `ink-3`. `ink-4` используйте только для декора.
- Минимальная зона клика — 40 px. У кнопок 48 px.
- Статусы и серии не различаются только цветом: всегда есть подпись.

- акценты `scuti` и `demo` те же. Контраст на тёмном фоне проверьте заново.

## 10. Чего не делать

- Не заливать кнопки, бейджи или фоны красным и спектром.
- Не делать подложку страницы белой: страница — `paper`, белые только панели.
- Не ставить тени на карточки и не применять glassmorphism, неон, фиолетовые градиенты.
- Не набирать заголовки жирным 700 и не использовать Google Sans в основном тексте.
- Не мешать скругления случайно: держаться шкалы из раздела 4.
- Не красить текст в цвета серий или статусов.
- Не добавлять эмодзи, стоковые 3D-иллюстрации и «AI-шаблонные» сетки из трёх одинаковых карточек с иконками в цветных квадратах.

## 11. Чек-лист для агента

1. Подключить три шрифта, задать токены (раздел 9) и базовые стили `body`, `::selection`, `:focus-visible`.
